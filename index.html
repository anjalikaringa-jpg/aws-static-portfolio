Project Architecture: This portfolio website is securely deployed using enterprise cloud infrastructure standards. The static asset is hosted inside a private, locked-down Amazon S3 Bucket and distributed globally through an Amazon CloudFront Content Delivery Network (CDN).

By leveraging CloudFront's Origin Access Control (OAC), the S3 storage layer remains entirely private to the public internet, preventing direct access and securing the infrastructure against unauthorized entry or data scraping.
